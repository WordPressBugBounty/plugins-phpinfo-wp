== Description ==

**phpinfo() WP** is een moderne, actief onderhouden plug-in voor de gezondheid van WordPress-sites en serveraudits. Het is de exacte tool die freelancers en bureaus op elke nieuwe site installeren om direct te zien *wat er mis is, wat er kapot gaat en wat er gerepareerd moet worden*, allemaal zonder een SaaS-abonnement, zonder externe dashboards en zonder het WordPress-beheerderspaneel te verlaten.

Zie het als de officiële plug-in **"Health Check & Problemen oplossen"**, maar gebouwd voor professionele productiesites. Onze probleemoplossingsmodus werkt volledig in een sessie per gebruiker. Bezoekers en klanten blijven de live site normaal zien terwijl u conflicten veilig kunt opsporen en isoleren zonder ook maar één seconde downtime.

== Installation ==

1. Install from your WordPress admin: **Plugins -> Add New** and search for *"phpinfo() WP"*.
2. Activate.
3. Find the **phpinfo() WP** menu in your admin sidebar.
4. (Optional) Purchase a Pro license and activate it from **phpinfo() WP -> License**.

U kunt ook [de zip downloaden](https://downloads.wordpress.org/plugin/phpinfo-wp.zip) en deze uploaden via **Plug-ins -> Nieuwe toevoegen -> Plug-in uploaden**.

= Server requirements =

* PHP 7.3 of hoger. PHP 7.4 heeft in november 2022 het einde van zijn levensduur bereikt en wordt niet langer ondersteund.
*WordPress 5.9 of hoger.
*Sommige PHP-functies die door de plug-in worden gebruikt, zijn mogelijk uitgeschakeld door uw host. Neem contact op met uw host als de functies niet beschikbaar zijn.
* Voor .htaccess-bewerkingen moet de hoofdmap van uw site beschrijfbaar zijn.

== Frequently Asked Questions ==

= Is the free version still free? =

Ja. De gratis phpinfo-viewer, .htaccess-editor, extensielijst, activiteitenlogboek, PHP EOL-tijdlijn en Config Grader-samenvatting zijn 100% gratis en dat zal altijd zo blijven. Pro is een optionele upgrade voor bureaus en serieuze site-eigenaren.

= Does the Pro version send my data anywhere? =

Nee. Alle audits draaien op uw eigen server. De Pro-licentiecontrole pingt één keer per week naar onze licentieserver om te bevestigen dat uw sleutel nog geldig is en dat er niets anders wordt verzonden.

= Can I use one license on multiple sites? =

De Single Site-licentie werkt op 1 site. De Unlimited-licentie werkt op elke site die u bezit of beheert. De levenslange licentie is ook onbeperkt.

= How does white-label work? =

Klik op de pagina Pro Audit Report op **White-label** om uw bedrijfsnaam, rapporttitel, accentkleur en voettekst in te stellen. De PDF die u genereert, maakt gebruik van uw branding, niet die van ons.

= What if my license server is unreachable? =

De plug-in werkt prima gedurende 14 dagen, zelfs als onze licentieserver niet bereikbaar is. Daarna worden de Pro-functies vergrendeld en moet u de licentie opnieuw activeren. U krijgt ruim voordat dit gebeurt een duidelijke kennisgeving.

= Will this slow down my site? =

Nee. Alle controles worden alleen in het beheerdersdashboard uitgevoerd en er is geen enkele impact op de prestaties van uw front-end. Zware controles (beveiligingsheaders, SSL) worden in de cache opgeslagen.

= How is this different from Health Check & Troubleshooting? =

Health Check & Probleemoplossing is de officiële WordPress.org-plug-in voor dit soort werk en is een solide hulpmiddel. De probleemoplossingsmodus is voor de hele site beschikbaar. Indien ingeschakeld, ziet elke bezoeker het standaardthema met uw plug-ins gedeactiveerd totdat u de modus uitschakelt via een link met één klik in de beheerdersbalk.

phpinfo() WP hanteert een andere aanpak. Onze probleemoplossingsmodus is per gebruiker: alleen uw huidige beheerderssessie ziet gedeactiveerde plug-ins en het standaardthema. Elke andere bezoeker en beheerder blijft de live site normaal zien. Dat is de ontwerpkeuze die we hebben gemaakt voor het debuggen van plug-inconflicten op drukke productiesites, zoals een live WooCommerce-winkel of een uitgever met veel verkeer, waar het offline halen van de front-end geen optie is.

We voegen ook functies toe die Health Check niet biedt: PHP EOL-tracking, A-F-configuratiebeoordeling met oplossingen met één klik (Pro), een gezondheidsscorebord in de beheerdersbalk, SSL/headers-monitoring en een klantklaar PDF-auditrapport.

Gebruik Health Check als u de officiële tool wilt met een eenvoudige foutopsporingsmodus voor de hele site. Gebruik phpinfo() WP als u een foutopsporingssessie per gebruiker op een live site nodig heeft, plus de bredere auditsuite.

= How is this different from Query Monitor / WP Umbrella? =

Query Monitor is een ontwikkelaarstool voor het debuggen van afzonderlijke paginaladingen, wat een andere taak is. WP Umbrella, ManageWP en MainWP zijn externe SaaS-dashboards die factureren per site, per maand, wat handig is voor bureaus die alles in één externe console willen hebben.

phpinfo() WP Pro is voor de site-eigenaar of freelancer die één in-admin tool wil die PHP-gezondheid, configuratie, beveiligingsheaders, SSL en een klantklaar auditrapport omvat, zonder een maandelijks SaaS-abonnement en zonder de WordPress-beheerder te verlaten.

= Does this PHP compatibility scanner actually work on my managed host? =

Ja. In tegenstelling tot scanners die afhankelijk zijn van PHP_CodeSniffer of de `exec()`-functie, gebruikt onze scanner statische analyse die binnen WordPress zelf wordt uitgevoerd. Het werkt op Kinsta, WP Engine, SiteGround, Cloudways, Pantheon en elke andere beheerde host die shell-toegang beperkt.
